# Security Policy

We take the security of GatotAuth seriously. If you believe you have found a security vulnerability, please report it in accordance with this policy.

## Supported Versions

Only the latest release version is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

Instead, please send security reports via email to: **security@gatotauth.dev**

Please include the following information in your report:
- Affected module/platform (e.g., core, velocity, paper).
- Description of the vulnerability and its potential impact.
- Steps to reproduce or proof-of-concept exploit details.

We will acknowledge receipt of your report within 48 hours and work with you to patch the issue before publishing details.
